Esercizi da JSON

Trasforma un JSON in un quiz.

Incolla il file o trascinalo nel riquadro. Le formule LaTeX vengono composte, ogni risposta riceve subito il suo verdetto e alla fine trovi il riepilogo.

Opzioni
Formato del file 
{
  "title": "Trigonometria",
  "questions": [
    {
      "question": "Quanto vale \\(\\sin\\frac{\\pi}{2}\\)?",
      "options": ["0", "\\(\\tfrac12\\)", "1"],
      "correct": [2],
      "explanation": "Facoltativa.",
      "topic": "Facoltativo"
    }
  ]
}

correct accetta indici da 0, lettere ("C") o il testo della risposta. Con più valori la domanda diventa a risposta multipla.

Nel JSON il backslash va raddoppiato. Se incolli formule con il backslash singolo, vengono corrette in automatico.

Puoi anche usare "quizzes" con più quiz, oppure caricare più file insieme.
